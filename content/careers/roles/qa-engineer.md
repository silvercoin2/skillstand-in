## About SkillStandIn

Skill Stand In connects experienced technical professionals with AI-focused projects where human expertise is used to evaluate, validate, and improve AI-generated work.

We are looking for Software Engineers, QA Engineers, SDETs, and Test Automation Engineers with strong web testing experience to review browser-based testing workflows for AI-generated applications.

This role is focused on technical review and validation rather than simply executing test cases. You will determine whether automated browser tests are well-designed, reproducible, deterministic, and capable of producing reliable pass/fail results.

## What You'll Do

- Review browser-based test workflows for AI-generated web applications.
- Evaluate whether browser interactions are technically feasible, realistic, and reliable.
- Validate test setup, fixtures, test data, environment assumptions, and execution flow.
- Verify that assertions produce deterministic, unambiguous pass/fail outcomes.
- Identify flaky tests, race conditions, timing issues, hidden dependencies, and unreliable selectors.
- Review AI-generated testing approaches and scoresheets rather than accepting AI output at face value.
- Provide concise, structured technical feedback and defend scoring against practitioner QA standards.
- Work independently and asynchronously to deliver high-quality evaluations.

## What We're Looking For

- 3+ years of professional experience in Software Engineering, QA Engineering, SDET, Test Automation, or a related technical role.
- Strong experience testing modern web applications.
- Hands-on experience with browser automation frameworks such as Playwright, Cypress, Selenium, or comparable tools.
- Experience creating, debugging, or reviewing automated UI and end-to-end tests.
- Strong understanding of test isolation, fixtures, test data, setup/teardown, reproducibility, and deterministic testing.
- Understanding of browser behavior, DOM interactions, selectors, asynchronous operations, network requests, and application state.
- Ability to identify common causes of flaky browser tests.
- Strong debugging and technical problem-solving skills.
- Ability to review unfamiliar code and quickly determine whether an implementation is technically correct.
- High attention to detail and ability to communicate technical issues clearly in writing.

## AI-Assisted Engineering

AI tools may be part of the workflow, so we are particularly interested in engineers who know how to use AI effectively while maintaining strong engineering judgment.

Ideal candidates can:

- Use AI coding assistants to accelerate review, testing, debugging, and evaluation.
- Critically evaluate AI-generated code and test cases.
- Detect incorrect assumptions, hallucinated APIs, weak assertions, and incomplete test coverage.
- Independently verify AI-generated solutions through code inspection and execution.
- Improve AI-generated work rather than blindly accepting its output.

Experience with tools such as ChatGPT, Claude, Cursor, GitHub Copilot, or similar AI-assisted development tools is valuable.

## What Success Looks Like

Successful reviewers can examine a browser-testing workflow and confidently answer questions such as:

- Can this test execute reliably in a clean environment?
- Does the test depend on state created elsewhere?
- Are the setup and fixture requirements complete?
- Are the selectors and browser interactions robust?
- Could asynchronous behavior introduce race conditions?
- Are the assertions testing the intended behavior?
- Would the same application consistently produce the same test result?
- Is a failure caused by the application, the test, or an ambiguous requirement?
- Has AI-generated code been independently verified?

The goal is to ensure every accepted test provides a clear, technically defensible, and reproducible pass/fail signal.
