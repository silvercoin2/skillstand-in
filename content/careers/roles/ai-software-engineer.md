## About the Opportunity

Skill Stand In is looking for an experienced AI Software Engineer to support a candidate through the final stage of an interview process for a Founding Engineer / AI Software Engineer position.

The original position is with an early-stage AI startup building a platform at the intersection of AI, real-time data, analytics, and prediction-market intelligence.

The interview process has already progressed to its final stage, which is an onsite technical interview.

We are looking for someone with strong practical engineering experience who can confidently handle deep technical discussions around system architecture, AI applications, backend development, data pipelines, and production engineering.

## Technical Background

You should have strong hands-on experience with:

- Python and FastAPI
- Next.js, React, and TypeScript
- LLM-powered applications and AI agents
- AI workflow and agent orchestration
- REST APIs and third-party API integrations
- Real-time or near-real-time data ingestion
- Data processing and analytical pipelines
- Backend architecture and scalable services
- Databases, caching, and production infrastructure
- Taking products from initial concept through production

Experience with financial technology, trading systems, prediction markets, market data, or analytics platforms is a strong plus.

## What You'll Need to Discuss

The onsite interview may involve technical and architectural discussions related to:

- Designing an AI-native application from the ground up
- Building reliable LLM and agent workflows
- Designing FastAPI backend services
- Building Next.js user-facing applications
- Integrating news, market, and third-party data APIs
- Real-time data ingestion and processing
- AI orchestration and analytical pipelines
- Database and API architecture
- Scalability, reliability, observability, and deployment
- Technical trade-offs in an early-stage startup
- Making independent engineering and product decisions

Because the target position is the company's first engineering hire, candidates should be comfortable discussing systems at both the implementation and architecture levels.

## Requirements

- 4+ years of professional software engineering experience
- Strong Python/backend engineering experience
- Hands-on experience with FastAPI
- Strong understanding of modern web application architecture
- Experience with Next.js, React, or comparable frontend technologies
- Practical experience building LLM applications, AI agents, or AI-powered workflows
- Strong API integration and data-pipeline experience
- Ability to explain technical decisions clearly and confidently
- Strong system-design and problem-solving skills
- Comfortable participating in an onsite technical interview

## Nice to Have
